COMP2406 Assignment 1 - Pet Haven

Open index.html in a modern web browser. No server or external library is required.

The images come with the Assignment 1 folder.

Design and implementation notes:
- The site uses the Pet Haven name and the slogan "Give love to every pet" on all the pages, ideas are from Chatgpt.
- Part C uses about.js, browse.js, pet.js and apply.js with the supplied data files.
- Shelter selection and pet type filtering are client-side. Pet and shelter IDs are passed in the URL between Browse Pets and Pet Details;
  the selected pet and fees are passed to the application form.
- Changes have made in the aboutData.js to change the originial name "New Home Animal Rescue" to my company name "Pet Haven".
- Changes have made in the shelterData.js to adjust the some image source code label (ex: change cat6.jpt to cat1.jpt)
- Applications are demonstration-only and are not sent to a server.
